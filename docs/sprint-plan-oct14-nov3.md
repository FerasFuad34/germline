## أوامر الانطلاق (للمهمة T2 — على جهازك)

```bash
# 1) قاعدة بيانات ARVO (metadata) — من صفحة الإصدارات
#    github.com/n132/ARVO-Meta  →  حمّل arvo.db
# 2) جرّب ثغرة واحدة أولاً (المثال الرسمي من ARVO):
docker run --rm -it n132/arvo:42487096-vul arvo
# 3) النسخة المُصلَحة:
docker run --rm -it n132/arvo:42487096-fix arvo
# 4) لاحقاً في أداة الاستخراج:  ثغراتنا المختارة تُقرأ من arvo.db
```

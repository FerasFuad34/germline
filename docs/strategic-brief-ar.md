## 0) الصورة في ثلاثين ثانية

| البند | التحديد |
|---|---|
| **المشكلة** | عالم 2026 يعيد كتابة البرمجيات بالـ AI (C→Rust وأمثاله). كل جيل جديد يُولد بـ**ذاكرة مناعية فارغة** — فيعيد ثغرات جده الأكبر وكأنها جديدة. |
| **المنتج** | **بوّابة التناظر المناعي (Immune Parity Gate):** تُشغّل «أمصال» كل الأجداد (ثغراتهم التاريخية) على الجيل الجديد قبل الدمج، وتُصدر **جواز مناعة موقّع** محمولاً مع السلالة. |
| **العميل الأول** | أي شركة تشحن برمجيات للسوق الأوروبي — لأن **الإبلاغ عن الثغرات صار إلزامياً قانونياً منذ 11 سبتمبر 2026**. |
| **الخندق** | أرشيف الأمصال المتراكم + شبكة السلالات + تعريف معيار تبادل مفتوح (ABX). |
| **الشعار** | SBOM يخبرك **بما داخل** الكود. الجينوم يخبرك **بما نجا منه** الكود — ويثبت أنه ما زال منيعاً. |

## 1) لماذا الآن؟ ثلاث رياح دافعة تتقاطع في هذه اللحظة بالضبط

### الريح الأولى: عصر إعادة الكتابة الجماعية بالـ AI 🏗️

- غوغل أعادت كتابة مكتبة **giflib** من C إلى Rust بالذكاء الاصطناعي آلياً (أعلنت أغسطس 2026)، وأصبحت أنظمتها **منيعة بنيوياً** أمام ثغرة Zero-Day حقيقية (CVE-2026-26740) قبل الإعلان عنها. [1][2]
- **DARPA TRACTOR:** برنامج وطني لترجمة كل كود C في العالم إلى Rust آلياً. [3]
- **CodeMender من DeepMind:** 72 إصلاحاً أمنياً مدموجاً في مشاريع مفتوحة المصدر خلال 6 أشهر فقط. [4]
- **DARPA AIxCC:** 7 أنظمة ذاتية (فائزة بجوائز بملايين) تُرقّع الثغرات ذاتياً — والخلاصة الأكاديمية: أنظمتها الفائزة **غير قابلة للاستخدام خارج فرقها**. [5]

> **الاستنتاج:** إعادة كتابة الكود لم تعد مشروعاً سنوات — صارت مشروع أسابيع. ومعنى ذلك: **ملايين الأجيال الجديدة تُولد شهرياً بذاكرة مناعية فارغة.**

### الريح الثانية: الفجوة المناعية موثّقة بالأرقام 🧪

- Copilot يعيد إنتاج كود مصاب من歷史 الثغرات **33% من المرات** — وكلما كانت الثغرة **أقدم**، زاد احتمال إعادة إنتاجها. [6]
- دراسة شاملة (SoK): الترجمات بين اللغات تُعيد توزيع أنواع الثغرات وتُنشئ فئات جديدة. [7]
- متوسط الزمن بين إدخال ثغرة وDiscoveryها في منظومة Rust وحدها: **770 يوماً**. [8]
- حتى غوغل نفسها، رغم 200 مليون جولة differential fuzzing، اكتشفت ثغرة قديمة أدخلها تعديل قديم **عن طريق مراجعة LLM شبه المصادفة** — لا بمنهجية. [2]

> **الاستنتاج:** لا يوجد اليوم أي آلية تضمن أن جيلاً جديداً **يرث مناعة** أسلافه. الهندسة المناعية (fuzzing) تولّد مناعة جديدة، لكنها **لا تحفظ القديمة**.

### الريح الثالثة: التنظيم — الباب صار إلزامياً 🏛️

قانون **CRA** الأوروبي (المناعة التنظيمية!):
- **11 سبتمبر 2026 (ساري الآن!):** التزامات المادة 14 — إبلاغ ENISA عن الثغرات المستغلّة فعلياً خلال **24 ساعة** من العلم بها. [9][10]
- يسري **بأثر رجعي على المنتجات الموجودة في السوق** — أي أنها مشكلة محفظتك الحالية لا منتجاتك القادمة. [11]
- **11 ديسمبر 2027:** الالتزامات الكاملة (SBOM، الأمن بالتصميم، علامة CE). [9][10]
- فترة دعم إلزامية ≥ 5 سنوات لكل منتج. [11]

> **الاستنتاج:** أصبح على كل شركة تبيع في أوروبا أن تعرف **بالضبط** ما نجا منه كودها وأين — وهذا بالحرف ما يبيعه الجينوم. SBOM يصف *المكونات*؛ لا أحد يصف *التاريخ المناعي*.

### حجم السوق 📈

- سوق أمن سلسلة التوريد: **2.87 مليار دولار (2025) → 13.14 مليار دولار (2034)** بمعدل نمو 18.4% سنوياً. [12]
- أوروبا هي المنطقة **الأسرع نمواً** — تحديداً بفعل CRA وNIS2. [12]
- سوق أمن المصادر المفتوحة وحده: ~6.45 مليار دولار بحلول 2034. [12]

## 2) لماذا هذه الزاوية **لا تشبه الفكرة الأصلية أبداً**

| المحور | الفكرة الأصلية (ShieldCode) | الجينوم المناعي (GENOME) |
|---|---|---|
| النشاط الأساسي | **توليد وتوزيع** ترقيعات | **التحقق من الوراثة** — لا نوزّع إصلاحات مطلقاً |
| القيمة المركزية | السرعة (ملي ثانية) | **الذاكرة والاستمرارية عبر الأجيال** |
| المستخدم | يشتبك مع الخصم وقت الهجوم | بوابة عادية في CI/CD، تعمل قبل الدمج |
| المخاطرة القانونية | توزيع كود تنفيذي على أنظمة الغير (كارثة) | إصدار **اختبارات موقّعة** فقط — المالك هو من ينفّذها |
| الفيزياء | مستحيلة (الترقيع يحتاج تحققاً بشرياً) | ممكنة اليوم (الاختبارات تُشغَّل تلقائياً) |
| علم الأحياء المستخدم | مناعة القطيع + المضادات | **الوراثة الجينية + الذاكرة المناعية** (النسيان المناعي هو المرض!) |

**درجات السقوط السابقة التي نتجنبها:** فكرة توزيع المضاد التلقائي جُرّبت وفشلت (Welchia 2003)، ومناعة القطيع جُرّبت تجارياً وفشلت (Cisco Immunet، أُغلقت يناير 2024). الجينوم يقف على أرض صلبة قانونياً وتقنياً.

## 3) المعمارية — المكوّنات الأربعة

```
┌────────────────────────────────────────────────────────────────────────────┐
│                           GENOME — المعمارية                                │
│                                                                            │
│  ┌────────────────┐   ┌────────────────┐   ┌────────────────┐   ┌────────┐  │
│  │ A. مستخرج      │   │ B. رسم السلالة │   │ C. بوابة       │   │ D. سجل │  │
│  │    الأمصال     │──►│    Lineage     │──►│    التناظر     │──►│ المناعة│  │
│  │ Antibody       │   │    Graph       │   │    المناعي     │   │ Registry│ │
│  │ Extractor      │   │                │   │ Immune Parity  │   │        │  │
│  └────────────────┘   └────────────────┘   │ Gate (CI/CD)   │   └────────┘  │
│                                            └────────────────┘              │
│  CVE/OSV/GHSA     gen0 ──► gen1 ──► gen2   في التدفّق: فشل/تحذير   Sigstore │
│  Git history       (C)    (patch)  (Rust)  + جواز مناعة          +شفافية  │
│  Exploit PoCs      + بصمات الدوال           + تقرير امتثال        + DHT    │
└────────────────────────────────────────────────────────────────────────────┘
```

### A. مستخرج الأمصال (Antibody Extractor) 🔬
**الوظيفة:** تحويل كل ثغرة مرّت على سلالة الكود إلى «جسم مضاد» = **اختبار قابل للتشغيل الدائم**.
- **المدخلات:** NVD / OSV / GHSA + تاريخ git (commit الإصلاح والاستغلال) + استغلاليات Proof-of-Concept مرخصة.
- **العملية:** توليد harness آلي (LLM + sanitizers) ← تشغيل على النسخة المصابة (يجب أن **يفشل**) وعلى النسخة المُصلَحة (يجب أن **ينجح**) ← توقيع ← نشر.
- **معيار القبول:** لا يُدرج مصل إلا إذا أثبت التمييز (fail-on-vulnerable / pass-on-fixed). هذا يحل مشكلة الدقة الذاتية.
- **موجود أم جديد؟** LLM يكتب الاختبارات = موجود؛ التحويل المنهجي لتاريخ الثغرات إلى **أرشيف أمصال موقّع قابل للنقل** = لا يوجد أحد يفعله.

### B. رسم السلالة (Lineage Graph) 🧬
**الوظيفة:** تتبع الأنساب بين أجيال الكود: commit ← fork ← إعادة كتابة ← ترجمة لغة ← إعادة هيكلة AI.
- **التقنية:** DAG + بصمات على مستوى **الدالة** (function-level hashing + تشابه دلالي) لربط «جين» الكود بنسخه الجديدة حتى لو تغيّرت اللغة.
- **المخرج:** لكل قطعة كود: «جدّها الأكبر، وكل الثغرات التي مرّت في دمها».
- **موجود أم جديد؟** git blame / Software Heritage = أرشيف؛ لا أحد يبني **رسم مناعة وراثي** يربط الأجيال المُعاد كتابتها بثغرات أسلافها.

### C. بوابة التناظر المناعي (Immune Parity Gate) 🚪
**الوظيفة:** أهم مكوّن — وما سيشتريه العملاء.
1. مطوّر يفتح Pull Request (إعادة كتابة / fork / ترقية).
2. البوابة تستدعي **كل أمصال الأجداد** من السجل.
3. تشغّلها على الأرتي فاكت الجديد.
4. النتيجة: ✅ تناظر مناعي / ❌ «نسيان مناعي» مكتشف (هذا الجيل فقد مناعة جده!).
5. تُصدر **Immune Passport** موقّعاً + تقرير جاهز للامتثال.

**التعريف الرياضي (لفهم الفكرة):** التناظر المناعي محقّق ⇔ الجيل الجديد ينجح في **100%** من أمصال أسلافه. أي فقدان = «دَين مناعي» يجب تسويته قبل الدمج.

### D. سجل المناعة الموقّع (Immune Registry) 🗄️
- أمصال وجوازات **موقّعة** (Sigstore) ومسجّلة في سجل شفافية (transparency log) — قابلة للتحقق من أي طرف.
- **مبدأ «المناعة تبقى حية حتى لو مات حاملها»:** لو أُغلق المشروع أو مات المشرف أو حُذف المستودع — الأمصال وجوازاتها محفوظة وموثقة، والجيل القادم يرثها بنفس المصدر.
- خيار DHT/لامركزي للأجيال الحرجة — هنا **يُستخدم** مفهوم الشبكة الموزعة، لكن لنشر *اختبارات موقّعة* لا أكواد تنفيذية.

**تدفق البيانات الكامل:**
```
ثغرة تاريخية → [A] مصل موقّع → يُحفظ في [D]
                                    ↓ (عند أي PR)
سلالة الكود ──► [B] الأجداد مَن؟ → [C] تشغيل أمصال الأجداد كلها → جواز → [D] توثيق
```

## 5) خطة الـ MVP — 90 يوماً

**الفلسفة:** لا نبني منصة. نبني **قصة واحدة مقنعة** ونطرحها على العالم مفتوحة المصدر.

| الأسبوع | الهدف | المخرجات الملموسة |
|---|---|---|
| 1–2 | اختيار مكتبة حاملة للقصة + بناء بيانات السلالة | giflib (أو zlib): استخراج كل CVE + commits الإصلاح + ربطها بالأجيال |
| 3–6 | **مستخرج الأمصال v0** | توليد ≥ 30 مصلاً آلياً لثغرات حقيقية، مع تحقق fail/pass تلقائي؛ قياس نسبة الدقة |
| 7–9 | **البوابة v0** | GitHub Action: يقرأ السلالة، يشغّل الأمصال، يُصدر Immune Passport موقّعاً (Sigstore) |
| 10–12 | **تجربة الإثبات العامة 🎯** | نأخذ مكتبة أُعيدت كتابتها بالـAI (على نمط تجربة giflib) أو نعيد كتابة دالة حرجة بأنفسنا → نشغّل الأمصال → ننشر «أول جواز مناعة وراثية عام» + مقال تقني + عرض على المشرفين |

**تجربة الإثبات (Experiment #1):** السؤال العلمي: *هل إعادة كتابة الذكاء الاصطناعي تحافظ على المناعة الوراثية — أم تُنشئ نسياناً مناعياً؟* هذا سؤال **لم يُنشر عنه شيء** حتى الآن، والإجابة عنه ستحدد مصير فئة كاملة من الأدوات.

**مؤشرات النجاح (KPIs):**
- ≥ 30 مصلاً مُولّداً آلياً، معدل إيجابيات كاذبة < 10%.
- زمن توليد المصل: من CVE إلى مصل متحقق < 48 ساعة (تكلفة < $10).
- تجربة giflib تجد **نسياناً مناعياً واحداً حقيقياً على الأقل** → هذه هي القصة الإعلامية.
- 3 مشرفين لمشاريع OSS يجرّبون البوابة طوعاً.

**قاعدتا الحكم (Kill Criteria):** إذا لم نجد نسياناً مناعياً واحداً خلال 90 يوماً، أو تجاوزت الإيجابيات الكاذبة 25% → نُعيد التفكير في النطاق (نحو اللغات عالية الخطر فقط).

## 6) السوق: من يدفع ولماذا الآن

| الشريحة | الألم | لماذا تشتري منّا |
|---|---|---|
| **شركات تبيع في أوروبا (CRA)** — الأولوية القصوى | إبلاغ خلال 24 ساعة عن ثغرات مستغلّة، على محفظة موجودة في السوق أصلاً. «هل نعرف حتى ما نجا منه كودنا؟» | الجواز = دليل قابل للتحقق وسجل جاهز للامتثال |
| **فرق منصّات وهندسة (Platform/DevSecOps)** | ترحيلات Rust وإعادة كتابة مستمرة تفقد الثقة | بوّابة واحدة تحمي كل جيل قادم |
| **أدوات ومولّدات الكود بالـAI** | 62% من الكود المولّد فيه ثغرة؛ يحتاجون فرقاً | يرخّصون البوابة كطبقة ثقة فوق مخرجاتهم |
| **مشاريع OSS حرجة ومرعاتها** | الفشل التاريخي المتكرر (OpenSSL, Log4j, xz) | مجاني/مخفض + حياد |
| **شركات الترحيل إلى Rust** | عميل: «كيف نضمن أن الترجمة لم تفقد حمايات قديمة؟» | التناظر المناعي = بند تعاقدي |
| **قطاع الدفاع/الحكومة** | موجة C→Rust وطنية (على نمط TRACTOR) | إثبات وراثي مطلوب للأنظمة الحرجة |

**تقدير حجم قابض علينا (رأسي):**
- TAM (أمن سلسلة التوريد): ~3 مليارات دولار في 2026. [12]
- SAM (طبقة التحقق/SCA الجديدة): 1.4–2 مليار دولار. [13]
- SOM (سنة 3): 5–15 مليون دولار ARR — إذا فزنا بـ 100–300 عميل مشترك في بوّابة + سجل + تقارير امتثال.
*(أرقام تقديرية للتخطيط لا للاستثمار.)*

## 7) المنافسة: نحن نجيب سؤالاً لم يسأله أحد

| الطبقة | المنافسون | السؤال الذي يجيبونه | لماذا لا يسدّون حاجتنا |
|---|---|---|---|
| SCA / فحص التبعيات | Snyk, Endor Labs, Socket, Mend, Black Duck, Sonatype | «هل يستدعي كودك الدالة المصابة؟» (reachability) | مؤخّرهم الزمني = **النسخة الحالية فقط**؛ لا علاقة بالأنساب ولا الأجيال ولا الوراثة |
| الترجمة إلى Rust | DARPA TRACTOR, غوغل (داخلية) | «هل نستطيع الترجمة بأمان؟» | يراقبون **السلوك** (differential fuzzing) لا **العدوانية**؛ لا أرشيف أمصال محمول |
| إصلاح/اكتشاف بالـAI | Big Sleep, CodeMender, Buttercup (مفتوح), AIxCC | «هل نجد الجديد ونصلحه؟» | مناعة **جديدة**؛ لا يحفظون القديمة؛ أنظمة AIxCC الفائزة «غير قابلة للاستخدام خارج فرقها» |
| provenance / أرشيف | SLSA, Sigstore, Software Heritage | «من بنى هذا؟ وما داخله؟» | وثائق وتواريخ — ليست مناعة قابلة للتشغيل |
| **GENOME** | — (الفراغ) | **«بمَ نجا هذا الكود؟ وهل ورث الجيل الجديد ذلك؟»** | — |

**التموضع بجملة واحدة:** *«نحن سجل الوراثة المناعية للبرمجيات — حيث SBOM يصف المكونات، نحن نصف الدم»*.

| **خدمات إنقاذ التراث** | مشاريع | فحص جيني كامل للمحفظة القديمة عند الاستحواذ/الطرح/الترحيل |

**مبدأ حاسم:** البوابة **تجيب على سؤال، لا تفعل فعلاً** في أنظمة العميل. لا تنفّذ ترقيعاً، لا تلمس الإنتاج. هذا يحسم أطول اعتراضات المبيعات (المسؤولية) — عكس أي فكرة تعتمد على «التطعيم التلقائي».

## 9) الخندق (Moat) — لماذا لا تُنسخ بسهولة

1. **أرشيف الأمصال يتراكم مركّبياً:** كل ثغرة في العالم = مصل جديد؛ من يبدأ أولاً يملك أكبر ذاكرة، والذاكرة أغلى من الخوارزمية.
2. **المعيار (ABX — Antibody eXchange):** نُعرّفه وننشره مفتوحاً مثل STIX؛ المعيار يجرّ المنظومة خلفه (نافذة زمنية 18–24 شهراً قبل أن ينسخه كبار).
3. **شبكة السلالات:** كل مشروع يُفحص يُغني الرسم؛ بيانات لا تتوافر لأي منافس منفرد (تأثير الشبكة).
4. **الحياد:** غوغل ومايكروسوفت لا يمكن أن يكونا «كاتب عدل المناعة» للعالم — لا يثق بهما منافسوهما. الحياد في السجلات سلعة نادرة.
5. **الأسبقية الأكاديمية:** نشر ورقة «النسيان المناعي في إعادة الكتابة بالـAI» يجعلنا المراجع، لا مجرد منتج.

|---|---|---|
| جودة الأمصال المولّدة بـLLM (إيجابيات كاذبة) | عالية | معيار القبول الصارم (fail-on-vulnerable/pass-on-fixed) + مراجعة بشرية للأمصال الحرجة + قياس دقة علني |
| «جواز مناعة» يُفهم كضمان مطلق → مسؤولية | متوسطة | لغة قانونية: الجواز = *دليل إجراءات مُنفّذة موقّع*، لا ضمان خلود. مثل شهادات الاختبار لا أكثر |

| نسخ من عمالقة الأدوات (Snyk/GitHub) | متوسطة | إسراع نشر المعيار + الشراكات قبل أن يصبح «ميزة» لا «فئة» |
| قيود المؤسس (طالب، اليمن، موارد) | واقعية | OSS-first (توزيع من GitHub)، تسويق بالمحتوى البحثي (المقالات المرجعية)، بلا مكتب، تكاليف تشغيل < $500/شهر في المرحلة الأولى، شراكات أكاديمية |
| انزلاق نحو «واجهة فوز فقط» | متوسطة | كل قرار يقاس بمؤشر: كم نسياناً مناعياً حقيقياً اكتشفنا؟ |

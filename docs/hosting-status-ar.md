1. **تنظيف الطابور**: إلغاء كل النشرات المعلّقة/العالقة لتجنّب نفايات عند العودة.
2. **محاولات نشر متكررة**: كل دفعة إلى `main` تُعاد فيها محاولة النشر تلقائياً
   (autoDeploy مفعّل) — بمجرد التعافي ستُدفع آخر نسخة.
3. **مرآة ثابتة مستقلة**: `site/` + `.github/workflows/pages.yml` — صفحة كاملة
   ببيانات المصـل والبوابة ونقاط JSON الخام، تُحدَّث آلياً مع كل دفعة،

4. **فحص ما-قبل-الدفع**: `tools/preflight.sh` — يمنع دفع أي شيء سيرفضه CI.

## خطوات عند عودة Render (دقيقتان)

1. راقب الصفحة: <https://status.render.com> — انتظر عودة الحالة إلى `All Systems Operational`.
2. اطلب نشرة يدوياً: لوحة Render ← خدمة `germline` ← **Manual Deploy → Deploy latest commit**.
   (أو أرسل لي رسالة — أطلقها عبر الـAPI وأتحقق من كل نقاط النهاية فوراً.)
3. تحقّق: `curl https://germline.onrender.com/api/corpus` يجب أن يعرض 100 مصل / 3 موثّقين / نسخة `0.1.1-demo`.
